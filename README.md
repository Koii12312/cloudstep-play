# Cloudstep (web build)

Play in the browser: https://koii12312.github.io/cloudstep-play/

2D pixel-art platformer made in Godot 4.7 for GAME 405 (SCAD).
Controls: A/D move, Space jump, X meow, hold S liquid cat, F swing, hold C climb, M map, Esc menu.

This repo holds only the exported game files.
